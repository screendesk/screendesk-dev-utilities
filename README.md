## Privacy

- No backend. Files, tokens, logs, and recordings you put into a tool are processed in your browser and never uploaded.
- The camera and microphone tests only access your devices after you allow it. The mic test's 5-second recording stays in memory for playback and is never uploaded.
- The HAR analyzer and `har-sanitizer` exist because HAR files carry live session cookies. Sanitize them before you share them.

## Run it locally

```sh
git clone https://github.com/screendesk/screendesk-dev-utilities
cd screendesk-dev-utilities/web
npm install
npm run dev          # http://localhost:3000
npm run build        # static site in web/out, host it anywhere
```

Requires Node.js 20.9 or later. Built with [Next.js](https://nextjs.org), [React](https://react.dev), [Tailwind CSS](https://tailwindcss.com), [Heroicons](https://heroicons.com), and [clsx](https://github.com/lukeed/clsx). No other runtime dependencies: parsers, formatters, the MD5 implementation, the diff algorithm, and the cron parser are all written from scratch in `web/src/components/tools`.

## har-sanitizer

```sh
cargo install har-sanitizer
har-sanitizer sanitize capture.har      # writes capture-sanitized.har
har-sanitizer scan capture.har          # exits 1 if it finds secrets, for CI
```

See [`crates/har-sanitizer`](crates/har-sanitizer) for the full CLI, the Rust library, and the WebAssembly package.
